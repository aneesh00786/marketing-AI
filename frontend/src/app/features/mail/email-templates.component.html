Email Templates

Reusable designs for emails, drafts and campaigns. Using a template makes a copy, so editing an email never changes the template.

You can view and use templates. Creating, importing and editing templates needs the Member role or higher.

Import templates from a ZIP package

Upload one HTML file (e.g. index.html) with its CSS files and images (PNG, JPG, GIF, WebP) in any folders, such as css/style.css and images/logo.png. Relative links are resolved, CSS is embedded and images are hosted for you. If the package has several HTML files, you choose the main one. You see a preview before saving; nothing is saved until you press Save.
