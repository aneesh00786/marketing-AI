Setup steps in ZeptoMail
  1. Create this workspace's webhook URL here and copy it.
  2. In ZeptoMail, open the Mail Agent you send with → Webhooks → Add webhook, and paste the URL.
  3. Select the events: Delivered, Soft bounce, Hard bounce, Open, Click, Feedback loop (spam).
  4. Turn on authentication; copy the Authentication Key and save it here.
  5. Use "Send test" in ZeptoMail and confirm the event is received before relying on it.
