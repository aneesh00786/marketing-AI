  1. Open the Zoho API Console with the Zoho account that owns your Zoho Campaigns, click Add Client and choose Server-based Applications.
  2. Enter these two addresses exactly:
    Homepage URL
    {{ app.homepageUrl }}
    Authorized Redirect URI
    {{ app.redirectUri }}
  3. Create the client, then in its Settings turn on Multi-DC so Zoho accounts in any data center (EU, India, Australia…) can connect.
  4. Copy the Client ID and Client Secret into the form below and save.
  5. Click Connect Zoho below and approve access in Zoho.
